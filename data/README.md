# Distance Estimation Plugin Data

This directory contains retained data for the distance estimation plugin.

- `calibration/` holds calibration imagery used to derive or verify stereo camera parameters.
- `samples/` holds representative input images and PCOT workflows for manual testing and regression checks.

Keep generated outputs, exploratory notebooks/scripts, old submissions, and large personal workbench folders outside this tree. Use `pcotplugins/distance_estimation_plugin/local/` for scratch files that should not be committed.
